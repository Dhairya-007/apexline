# Apexline — playable build

This branch holds the generated WebGL player. It is **build output, not source**
— do not edit it by hand.

Source: https://github.com/Dhairya-007/apexline

Regenerate with:

```
Unity -batchmode -quit -projectPath . \
  -executeMethod Apexline.EditorTools.ApexlineBuild.WebGL
```
